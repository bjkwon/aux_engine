This is how a class is defined in auxe.

1. A .aux file with the class name has the following structure
(myclass.aux)

class myclass
// member variable declarations or definitions
id=0
name=""
grade

//This is a constructor; optional
method myclass(i,n)
id=i
name=n

// This is a member function or method
method out=myfunc(arg)
out=name++sprintf("%d",id)

// End of myclass.aux


2. Rules
- Member variables must be declared or defined in the class definition .aux file.
- New member variables not listed in the class definition cannot be added runtime.
- Member variables are type-blind, i.e., a member variable can become a different type runtime.
- Use myclass() to instantiate a class with no constructor or zero constructor arguments; bare myclass is a variable lookup.

3. Example usage:

u=myclass(100,"bjkwon")
u.grade="A" // OK
u.address="1234" // Error
u.myfunc(0) // should return "bjkwon100"

If the class does not have a constructor, instantiate with empty parentheses:
u=myclass()
